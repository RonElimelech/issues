### Goals
- The trainee will gain hands-on experiance with deploying applciation on the Openshift platform.

### Tasks
- Log into our MedOne environment:
  - Verify OpenVPN is downloaded on your machine.
  - Request your trainer for your user credentials and to provide VPN connection configuration file.
  - Import file in OpenVPN and specify your user credentials.
  - Enable VPN connection. 
  - Ask trainer for Openshift cluster url and Project name.
- In your openshift project called `trainee-playground-<name>`, deploy the following:
  - Create a serviceAccount with NSView permissions is your namespace. 
  - Connect to it and verify you can list all `networkpolicies` in your namespace. Attempt to create a deployment with those credentials. Does it work? why?
  - An httpd deployment with 3 replicas, one in each Availability Zone of the cluster. The deployment will display an "Hello World!" message in its page.
  - Expose the deployment with a route. Verify you can connect to it from your local web browser.
  - Create a RHEL8 virtual Machine in AZ-C from a template and configure key based ssh connection from your local machine.
  - Connect a secondary disk called "data01". Make sure RWX.
  - Connect to the Console of the VM and cURL your "Hello world!" route. (Verify proper response).
- After finishing this task. Make sure to notify trainer to delete the Project.

NOTE: When possible, use YAML definition and `oc apply -f` instead of creating resources with a `oc` cli commands. Defining YAMLs will be extremly helpful when starting to automate application deployments.
