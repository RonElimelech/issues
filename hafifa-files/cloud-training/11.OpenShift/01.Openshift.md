### Goals
- The trainee will gain basic knowledge for managing and deploying client applciation in the Openshift platform.

### Tasks
- Complete the Red Hat OpenShift Administration I [DO180 Course](https://rol.redhat.com/rol/app/courses/do180-4.14/pages/pr01) (All Chapters).

  - Users, groups and serviceAccounts
  - Roles, cluterroles, rolebinding, clusterrolebinding
  - k8s context and kubeconfig
- Read about the Kubevirt project and Openshift Virtualization operator.
  - Kubevirt & Openshift Virtualization (CNV)
  - VirtaulMachine, virtualmachineinstance, virt-launcher pod
  - Virtual Machines templates

##### Leading Questions (DO180)

**Chapter 1. Introduction to Kubernetes and Openshift:** 
- Explain the relationship between Kubernetes and Docker. Does Kubernetes use Docker? Does it have to use Docker? What are alternatives to Docker?
- What is k8s? What is Openshift? How are they related?
- What is the smallest manageable unit in Kubernetes?
- What is the difference between containers and pods?
- Why would one group a couple of containers into a single pod?
- What is an init-container?

**Chapter 2. Kuberenetes and openshift Command-line Interfaces and APIs:**
- Explain what kind of information/configuration will be specified inside each of these YAML fields (Give an example for each field):
  - `.kind`
  - `.metadata`
  - `.spec`
  - `.status`
- What is `ownerReference` in the `Metadata` section?
- What are labels and annotations, how do we use them? Explain the different use cases.
- Perform the following with `oc` cli:
  - How would I list all services in a namespace?
  - How would I list all pods in the entire cluster?
  - How would I see details on a specific deployment in my namespace?
  - How would I print the YAML of a specific resource with `oc` cli?
  - What is the field of `revisionHistoryLimit` in a deployment used for? (Use `oc explain`)
- Explain the difference between declarative and imperative configuration.
- What are `events` in OpenShift? How would I see them?

**Chapter 3. Run Applications as Containers and Pods:**
- How would I connect and run a command inside a running pod? List a few options.
- How would I inspect container's logs?
- What's the difference between pod logs and Openshift events?

**Chapter 4. Deploy Managed and Networked Applications on Kubernetes:** 
- How resources are represented in K8S?
- What is a CRD?
- What is the difference between `ConfigMap` and `Secret`?
- What's the difference between `Deployment`, `DeploymentConfig`, `Statefulsets` and `Daemonset`?
- What is deprecated/not supported, deployment or DeploymentConfig?
- What's the relationship between replicaset and deployment? How would I manually rollout a deployment in openshift?
- What are `CronJobs`?
- What are `Secrets`? In what format are they saved?
- What's the difference between `ConfigMaps` and `Secrets`?
- Why do I need a `Service`? What is a headless service?
- What are NetworkPolicies?
- When would I use Routes and when would I need to use a Service of type LoadBalancer?
- What is a sticky session? Why would you use it? 

**Chapter 5. Manage Storage for Application Configuration and Data:**
- What happens to pods that use a volume mount to reference secrets or configuration and they are updated?
- How would I store data persistently? 
- What is the difference between a PV and a PVC?
- What are ReadWriteMany and ReadWriteOnce access modes?

**Chapter 6. Configure Applications for Reliability**
- What does it mean that a pod is "Ready"? How can I control when the pod is ready?
- Go over these error messages a pod may receive. Explain what can cause each issue. `ImagePullBackOff`, `Error`, `CrashLoopBackOff`, `OOM`,`Evicted`, `CreateContainerError`, Stuck on `Pending`.
- What are Readiness and Liveness probes? What do they do? How do Liveness probes know when an application is not available?
- What are resource limits and requests are used for? What is the difference between the `requests` and `limits`
- What is a resourcequota resource? What is it used for?

**Chapter 7. Manage Application Updates**
- Explain about all options of `imagePullPolicy`
- How does a default rollout occur in openshift? 

##### Leading Questions (DO280)

**Chapter 3. Authentication and Authorization**
- What is the difference between a user and a service account? How would I authenticate with an service account? How can I make permanent tokens for a service account?
- What is a rule? what is a role? 
- What is the differnece between a role and rolebinding?
- What is the difference between a role and a clusterrole?
- When running a deployment which user actually runs the pod?
- What is a k8s context?
- What is the `~/.kube/config` file and what is the meaning of its contents? How is it different for ServiceAccounts?

##### Leading Questions (DO316)

**General**
- Explain the general goal of the Kubevirt project, what is it? what is it used for?
- How is a VM represented in Openshift?
- Explain the relationship between VM, VMI and virt-launcher pod.
- What happens to the VM's vmi and virt-launcher pod when you click on the `restart` on the Openshift Console?
- How does networking work for a VM in openshift? Does it differ from Pod networking?
- How would I connect a service to a VM? how would I connect a route?
- How would I configure SSH access into the VM?
- How would I run a script on the VM first boot?
- What are virtual Machine templates used for?
