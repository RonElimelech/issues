# IDFcTS Teams

Our branch (IDFcTS) is structured into four departments, each made up of self-service teams delivering specialized services:

## CORE
- **Compute**: Manages OpenShift bare‑metal clusters.
- **Storage**: Manages Ceph block, object, and file storage.
- **Network**: Configures VPN and cloud connectivity.
- **Bare Metal**: Provisions and configures physical servers.
- **Ecosystem**: Oversees Kasten backups and virtualization.

## PLATFORMS
- **DBaaS**: Provides PostgreSQL, MongoDB, and Redis services.
- **SSO**: Runs Keycloak and IDM for single sign‑on.
- **Ingress**: Manages traffic routing and DNS.
- **Observability**: Offers Splunk, Grafana, and Mimir dashboards.

## BIG DATA
- **GPU**: Operates Run:AI GPU Operator, GPU-enabled VMs, and HPC research.
- **MLOps**: Maintains Triton, Dagshub, and MLflow pipelines.
- **MLaaS**: Delivers machine learning models as APIs.
- **Ingest**: Handles data ingestion via Kafka and NiFi.
- **Processing**: Provides ETL and analytics with Trino, Airflow, and Spark.

## CLOUD DEV
- **Serverless**: Runs serverless workloads with Knative.
- **Kubernetes Ecosystem**: Provides OpenShift as a service, ArgoCD, and Quay.
- **Portal**: Develops and maintains the cloud portal.
- **Support**: Manages the ServiceNow platform.
