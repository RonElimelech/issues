
### Goals
- Understand what is a webserver and its purposes 
- Be able to create and manage reverse proxies and simple load-balancers

### Tasks
- Apache (httpd)
  - Create a simple webserver which serves a single static page (hosted on the webserver)
  - Add password authentication to your page
  - Create a roundrobin load-balancer between 2 pages
  
- Nginx
  - Use Nginx to create a reverse proxy which returns static content from an Apache webserver
  - Using Nginx forward requests to the roundrobin Apache webserver from the previous task
