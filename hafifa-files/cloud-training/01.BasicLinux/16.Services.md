### Goals
- The trainee will understand the differences between processes and services
- The trainee will know how to list and inspect all the services on a Linux machine
- The trainee will understand what are Runlevels and what are their uses
- The trainee will understand how does `systemd` services work

### Tasks
- Read about Runlevels in Linux
- Provide a detailed explanation of the various roles and functions of each Runlevel.
- Read about `systemd` and answer the following questions:
  - Explain the different `systemd` targets and their purposes.
  - What commands can be used to list all services on a Linux machine utilizing `systemd`?
  - What are the steps to start a service using `systemd`? How can I stop it?
  - How can I check the status of a service?
  - How can I restart a service?
  - How can I make it so services start at system startup?
  - How can you configure a service to automatically start whenever the multi-user Runlevel is activated?
  - Create a simple `systemd` service that appends the date and time to a file every 20 seconds.
  - Explain what does `systemctl mask xxxxxx.service` do.
  - Bonus: How can I *analyze* service starup time?
- Boot into single-user mode and change the root password.
