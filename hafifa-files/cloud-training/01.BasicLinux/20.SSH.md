### Goals
- The trainee will understand the ssh protocol and how it works.
- The trainee will know the purpose of the important files in the context of SSH.
- The trainee will understand symmetric and asymmetric encryption and how they are used in the context of SSH.
- The trainee will understand the authentication process and different methods.
- The trainee will learn how to configure different types of tunnels.

### Tasks
- Read about the ssh protocol and understand it and answer the following questions.
  - What security features does SSH provide over other remote connection protocols?
  - Read about symmetric and asymmetric encryption. What kind of encryption method does SSH use during the handshake and data transfer stages?
  - Explain the SSH authentication process and how it works.
- Scenario: Create 2 vagrant machines. From now on we'll refer to them as 'server1' and 'server2'.
  - ssh to server2 from server1 using a password.
  - Now, let's do this with a key pair. Make it possible to connect to server1 from server2, use the `ssh-keygen` and `ssh-copy-id` commands.
  - If you'll destroy server1 machine and build it again (let's assume the ip address is static and remains the same)
    will you be able to ssh from server2 to server1 (doesn't matter the authentication method)? If not, what should you do to make it possible?
  - Create file1 in your server1 home directory. copy it to /tmp directory in server2.
  - Now copy the same file to your home directory and name it file2 (do it from server1).
- Read about the conecpt of SSH tunneling and answer the following questions.
  - What is SSH tunneling? What is it used for?
  - What are the differences between local and remote SSH port forwarding?
  - Using SSH tunneling, from **your home directoy**, use `ssh` to copy a file from server1 to server2.
  - Bonus: Read about `ssh -3` and use it to perform the previous task of copying files between two remote servers. How does it work? Does it differ from SSH tunneling?
