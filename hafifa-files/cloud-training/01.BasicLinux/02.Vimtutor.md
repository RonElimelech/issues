### Goals
- The trainee will understand how to work with Vim editor.

> Note: During your time using vim, opt to use the standard navigation keys (i.e., hjkl). 
> If you're interested about why hjkl are the chosen keys, feel free to read about it online.

### Tasks
- Complete the vimtutor (use the `vimtutor` command to open it).
- Answer the following questions:
  - Explain the 3 modes in `vim`
  - How can you delete 4 lines of text?
  - How can you delete everything behind the cursor?
  - How can you jump to the next bracket?
  - How can you paste some text?
  - How can you upward-search for the work "splendid"?
  - How can you change all the occurrences of the word "leet" to the word "1337"?
  - How can you select and indent multiple lines at once?
- Read about buffers in `vim` and answer the following questions:
  - What is a buffer? Why is it useful?
  - How can you open a new buffer?
  - How can you close an existing buffer?
  - How can I move between buffers?
  - How can I open a file in a new buffer?
- Bonus:
  - Read about neovim (`nvim`), try out a popular installation of nvim known as nvchad.
  - Install some popular `nvim` plugins and try them out (e.g., `telescope` + `ripgrep`). 
  - Try out https://www.vimgenius.com/ to hone your `vim` skills.
