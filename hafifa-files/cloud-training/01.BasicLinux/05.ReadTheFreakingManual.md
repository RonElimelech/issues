### Goals
- The trainee will know how to use the manual to look up information
- The trainee will learn about alternatives to man

> Remember, when in doubt, RTFM.

### Tasks
- Use the command `man man`, read the manual page of the man command
- How can you search all the manual pages that contains the word **echo**?
- Read about the `apropos` command. Does it differ from `man -k`?
- What does `man -wK <KEYWORD>` do?
- Read about `cheat.sh`. Run `curl cheat.sh/grep` and be amazed.
